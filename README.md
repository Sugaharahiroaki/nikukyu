# おにぎり〜NIKUKYU〜 — 専用デザインのサイト（試作）

大阪府のおにぎり専門キッチンカー「おにぎり〜NIKUKYU〜」（店主：柴田 佳典さん、夫婦で営業）のための1ページのサイト。
菅原農園（`custom/sugahara-nouen`）と同じく、TOMONI の共通CMSの型を使わない静的ファイル（HTML / CSS / JS / 画像）。
Nginx でも Next.js の `public/` でも、そのまま置けば動く。

```
index.html        本文
assets/site.css   見た目。色・書体・余白の値は先頭の :root にまとめている
assets/site.js    動き。GSAP（cdnjs）を使うが、読み込めなくても内容はすべて表示される
img/              写真（WebP）とロゴの元画像。出典は下記
```

## 設計

- 色はロゴの紺（`--ai`）、米の白（`--kome`）、鮭の橙（`--sake`）。紺の面には青海波の地紋（CSS の data URI）
- 書体は見出しが Shippori Mincho B1、本文が Zen Kaku Gothic New（Google Fonts）
- ロゴは Instagram のプロフィール画像（150px しか無い）を元に SVG で描き直したもの（`index.html` 冒頭の `<symbol id="logo">`）。正式なロゴデータをもらったら差し替える
- 最初の画面：全面写真4枚が6秒ごとにクロスフェード（ゆっくり寄る）。縦書きの見出しが1行ずつ立ち上がる。スマホでは横書きになる
- スクロール：紺の帯のマーキー、写真の視差、こだわり4項目（米・海苔・具・手）、メニューの札が1枚ずつ、店主の小さな写真が遅れて重なる
- `prefers-reduced-motion` が有効なら、切り替え・視差・登場演出はすべて止まる
- 問い合わせは「DM 用の文章をつくる」フォーム。お店の受け口が Instagram の DM なので、送信ではなく文章を組み立ててコピーする形。LINE やメールの受け口ができたら差し替える

## 未対応・要確認

- **店主の「想い」の文章は仮**（利用者の聞き取りを元に TOMONI が書いた一人称の文章）。アクションプランでは 10/10 に本人の録音→10/12 に文字起こしの予定。本人の言葉に差し替える。クラウドファンディング等に本人の文章があるとのことだが、CAMPFIRE・READYFOR・Makuake・For Good などを検索しても見つからなかった。URL が分かれば反映する
- **顔写真が無い**（店主・ご夫婦）。手元の写真で代用している。撮影予定（写真100枚）の中で「夫婦」を必ず
- メニュー6種（鮭・梅・ツナマヨ・塩むすび・なす味噌・焼きさば）は**デモ画像の並びで仮**。「なす味噌（期間限定）」以外は実際のラインナップを確認して差し替える。説明文も仮
- 「今週の出店予定」は**例**（だんじり、少年野球、平日お届け）。実運用では毎週の更新が要る。CMS に載せるなら「お知らせ」か専用の出店カレンダーで
- 猫の写真はデモ。看板猫がいるのか、店名「肉球」の由来は本人に確認（録音のテーマに「猫」が入っている）
- 拠点（藤井寺・羽曳野エリア？）はサイトに書いていない。確認できたら「出店について」に足す
- 公式 LINE は準備中。開設したらボタンを「お問い合わせ」と「出店について」に足す
- ロゴは SVG で描き直したもの。正式データがあれば差し替え

## 確認のしかた

`index.html` をブラウザで開くだけで見られる（書体と GSAP はネット経由）。

## 先方に見せる（確認用サーバー）

菅原農園と同じ手順。

```bash
# 開発PCから。ファイルを /srv/apps/tomoni-web/sites/nikukyu/ に置く（sudo 不要）
bash infra/review/publish-static.sh nikukyu /review/<トークン>

# 初回だけサーバーで。Nginx に location を足して、その URL でこのサイトを返す（sudo）
sudo bash /srv/apps/tomoni-web/deploy/static-site-install.sh nikukyu /review/<トークン>

# 見せ終えたら外す
sudo bash /srv/apps/tomoni-web/deploy/static-site-install.sh --remove nikukyu
```

`/review/` 配下で開かれたときは、上に「確認用ページ（公開前の案）」の帯が出る（`site.js`）。
